# 11 月 18 日：模型密钥、网卡直连和实板语音

测试环境是用户的 Mac、托管 OpenCode 2.2.5 和已配对的 ESP32-S31-Korvo-1。使用合成文本和语音，没有使用家庭数据或旧钥匙串中的模型 Key，没有打印，也没有使用 GitHub CI。

## 当前安装

- 本机通过 TypeScript/Vite、Rust release 和 Tauri App 打包。签名经 `codesign --verify --deep --strict` 检查，安装在 `~/小呆 Server/ESP Bot Server.app`。重启后托管 OpenCode 和设备 WSS 入口均恢复，日志记录服务启动、设备活动及音量上报；板端在空闲时报告 `secure_link=1`。
- 现有 `brain.json` 只改了 `harness.provider_network=active_interface`。保留了设备配对、三家端点与既有顺序，Qwen 的正式路线仍停用。只有隔离的测试进程临时启用了 Qwen。
- 模型 Key 由当前 App 进程持有，或由启动环境提供。配置重载和服务启停保留本次输入；完全退出 App 会丢弃本次输入。没有迁移、读取或删除旧模型 Key。修改本次密钥时，等待当前回合结束，仅重启托管 OpenCode，不要求设备重新配对。

## 接口连通不等于模型能回答

当时普通外网路由经 `utun6`，活动 Wi-Fi 为 `en0`。分别检查不带密钥的 `/models`、带故意无效凭据的聊天请求，以及官方 OpenCode 经本机转发发出的独立合成回合。表中状态来自实际供应商 HTTPS 连接；本地返回的 502 不算供应商响应。

| 服务商 | 在本机看到的结果 |
| --- | --- |
| DeepSeek | `/models` 返回 401；聊天接口和官方 OpenCode 回合在 `en0` 收到 401。 |
| Qwen | 修复转发时丢失客户端标识的问题后，`/models` 返回 200；聊天接口和官方 OpenCode 回合在 `en0` 收到 401。未验证套餐是否允许正式使用。 |
| GLM | 曾通过 `en0` 在 `/models` 和聊天接口收到 401。随后 CDN 解析到另一组地址，系统没有通往这些地址的 `en0` 路由；用同时期解析结果和独立 TLS 客户端复现。最后一次正式 OpenCode 回合未取得上游 HTTP 响应，转发报错且没有切回 VPN。不能认定 GLM 稳定直连。 |

直连只选择活动物理接口，重用连接前也重新检查活动网卡；保持服务商域名的 TLS 校验。没有硬编码 CDN IP、修改 macOS 路由或 VPN 设置。若需要消除 GLM 的间歇故障，先让 VPN 允许该端点轮换地址从物理接口访问，然后用「模型与密钥 → 测试网卡直连」复核。检查 DNS 和普通 HTTPS 可达性不需要模型额度。

本机 75 项常规 Rust 测试全部通过。两项可选真实网络测试分别检查三家端点和三条正式 OpenCode 请求，最后一次两项都因 GLM 直连失败未通过；DeepSeek 和 Qwen 均得到预期的鉴权拒绝。本次运行没有有效模型凭据，没有成功生成云端回答，也没有验证账户余额、生成内容或首字延迟。

## 本次密钥和对话界面

Rust 测试覆盖密钥的本次运行范围、配置重载、清除、回合占用时拒绝更换、公开状态及配置不包含密钥值、可选搜索工具的凭据，以及本机转发的地址与路径约束。

Mac 当时锁屏，未手动操作已安装 App 的原生窗口。浏览器检查使用打包好的正式前端和隔离的模拟 IPC：无密钥时保留草稿并提供设置入口；输入后清空密码框，能清除本次密钥，测试值未进入浏览器存储；网卡检查显示接口和 HTTP 码；失败后可以恢复原问题，已有新草稿不会被覆盖，恢复不会自动重发。测试没有把占位 Key 写进正式服务。

## 喇叭和唤醒

实板原设为「仅图文」。通过 USB 操作设备的正式设置页启用「图文＋语音」，保持 17/60、未静音。屏幕与板端 `spoken=1`、`volume=17`、`muted=0`、音频设置回执 `ESP_OK` 一致，随后重启后的板端日志仍保留这些值。本次没有重新刷写固件。

在 Mac 原有输出音量 13/100 下，仅播放一次合成的完整「小呆小呆」，这一声未触发实板播放，没有硬件开始或完成回执；没有提高音量或连续重试。本次复核不能证明低音量唤醒或音质。11 月 17 日，同一喇叭播放本地应答时用户确认声音清楚，真实云端对话的两段语音也各有硬件完成回执。声纹、ASR、记忆影响回答的前后对照和 Graphiti 的实际测试范围见[上一次专项验收](review-household-acceptance-2026-11-17.md)。
