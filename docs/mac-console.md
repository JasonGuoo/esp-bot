# 小呆 Mac 交互台

**交付状态：界面和接线源码已写入，尚未执行 Tauri 应用、TypeScript 编译、构建或测试。**
硬件仍在运输中；本页描述这次源码提供的操作入口和行为边界。

应用默认打开新的 **小呆** 页。它直接调用 Rust `bot-server` 的
`companion_request`，可以在没有机器人连接时使用 Mac 文字 / 语音交互。
原有设备 Chat、Events、设备发现与旧版软配对入口保留，标为诊断用途。

## 1. 入口与代码

| 文件 | 职责 |
| --- | --- |
| `server/bot-server/src/companion.ts` | 对话、家庭、记忆、身份、工具授权、配置和服务管理 |
| `server/bot-server/src/companion.css` | Mac 交互台布局、卡片、状态、表情和低动态效果模式 |
| `server/bot-server/src/capture.ts` | 显式麦克风 / 摄像头采集、WAV 格式、文件边界、资源释放 |
| `server/bot-server/src/capture-worklet.js` | 有界音频采集 AudioWorklet |
| `server/bot-server/src/main.ts` | 默认“小呆”页及原有 Chat / Events 的切换 |
| `server/bot-server/index.html` | 应用入口、中文导航和保留的设备诊断区域 |

没有新增 npm 依赖。麦克风采集复用浏览器标准 AudioWorklet / Media Capture 模式；
重采样交给 `OfflineAudioContext`，不另写声音处理引擎。
[AudioWorkletNode](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorkletNode)、
[OfflineAudioContext](https://developer.mozilla.org/en-US/docs/Web/API/OfflineAudioContext)、
[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。

worklet 通过 `new URL("./capture-worklet.js?no-inline", import.meta.url)` 加载。
`?no-inline` 保持独立的本地脚本资源，避免小文件被 Vite 转成 `data:` URL 后与
应用的 `script-src 'self'` 不一致。
[Vite 官方静态资源说明](https://vite.dev/guide/assets.html#explicit-inline-handling)

## 2. 第一次准备

在 **服务与设置** 读取 `brain.json`，实际路径显示在编辑器上方。按
[OpenCode 接入说明](mac-opencode.md) 准备 OpenCode、模型计划密钥和继承的 MCP；
按 [本地模型服务说明](mac-local-models.md) 准备 Python 依赖和本地模型。

点击 **保存并重载** 会停止当前互动、应用配置并重新开始界面对话；随后点击
**启动服务**。界面分别显示服务是否接受新轮次、OpenCode 健康状态和各条模型路线。
Qwen / GLM / DeepSeek 的顺序来自实际配置。额度未知时不会编造余额或百分比。

**查看模型状态** 是单独的显式操作。返回的 worker 就绪只表示本地协议能响应，
各模型是否安装 / 可用仍看具体 ASR、speaker、face、TTS 项。打开窗口不会自动
下载模型，也不会打开麦克风或摄像头。

## 3. 对话与声音

文字可以直接发送，也可按 `⌘ Enter` / `Ctrl Enter`。开始建议只是填入输入框，
不会自动启动模型请求。头像根据正在听、思考、朗读、完成等阶段切换本地表情；
它不代表机器人设备已经完成了同样的动作。

**录一段** 的流程是：

1. 点击按钮，浏览器向系统申请本次麦克风权限。
2. 再次点击结束，或到 30 秒自动结束。
3. 音频转换为 16 kHz、单声道 PCM16 WAV，麦克风随即关闭。
4. 检查“待发送”提示后，点 **发送** 才交给 Mac 本地 ASR 和后续回答流程。

也可以选择已存在的 WAV 文件。只接受 0.25–30 秒、16 kHz、单声道 PCM16；
不自动把任意视频 / 压缩文件送到模型服务。附上语音时文字输入暂时停用，与后端
“每轮只接受一种输入”一致。

本地 TTS 回复通过浏览器音频控件播放。系统阻止自动播放时，点击 **播放回复**。
窗口只保留最近三份可重播的音频，较早的文字仍可阅读。停止、换人、关闭窗口或
离开“小呆”页会关闭当前播放并撤销对应 Blob URL。

**停止** 会立即关闭窗口自己的麦克风 / 摄像头、停止播放、撤销本地媒体资源，并
向 Rust 发出取消。迟到的回复按轮次代数丢弃，不会突然接着说上一句话。
退出页面时也会进行本地清理；进程级取消、设备端音频取消仍由 Rust 和设备自己的
会话控制负责。

这不是 Mac 唤醒词服务。正式机器人仍由设备本地完整的 **小呆小呆** 关键词或
主动触摸发起会话。界面的录音按钮是一种明确的人工输入方式。

## 4. 屏幕卡片

回复由 Rust 校验后的 `speech`、`expression` 和 `cards` 构成。窗口支持文字、
步骤、图片（包括浏览器支持的动图）以及网页卡片。

模型文字、档案昵称、记忆和工具内容均通过 `textContent` / DOM 属性渲染。
只有固定的应用模板使用 `innerHTML`；模型不能提交 HTML 或脚本。

图片与网页需要 HTTPS，且域名必须出现在家长配置的
`conversation.media_hosts` 精确允许列表中。前端会再次检查域名、URL 凭据和端口。
图片采用延迟加载、禁止发送 referrer。网页使用空 `sandbox` 的 iframe，没有脚本、
同源、表单、弹窗、摄像头或麦克风权限。站点若拒绝嵌入，卡片的文字说明仍然保留。
配置改变并重载时会移除旧卡片。

未配置媒体域名时，回答仍有文字和步骤，受阻的远程媒体会在 Rust 端降级。
这里没有伪造图片地址，也不声称某一网页已经可以在 ESP 屏幕上播放。

## 5. 家庭、记忆和身份

上方 **本轮成员** 是唯一的显式身份选择。创建档案后，点击 **选择此人**，或者从
下拉框选择，才应用其个人记忆；同时创建新的 conversation ID，防止把另一个人的
上下文带过去。识别得到一个候选不会自动改变选择。

**记住一件小事** 支持家庭共享 / 个人归属、来源、分类、到期时间、确认标记和
云端可见性。当前 Qwen / GLM / DeepSeek 路线会使用云端模型，因此只有同时勾选
**我已确认内容**、**允许将这一条提供给云端模型** 的对应作用域记忆才参与回答。
保留仅本地的记录也可以，但不会在这些云端轮次中偷偷注入。

记忆清单支持搜索、编辑和删除。修改或撤销可见性后，协调器清理旧 OpenCode
上下文；窗口也重新开始对话，避免把旧文字继续当作当前记忆展示。
更多存储、保留和删除范围见 [Mac 本地记忆](mac-memory.md)。

### 人脸 / 声纹登记

选择成员和登记模态，添加配置要求数量的不同样本，默认至少三份。人脸可选
JPEG / PNG 或使用相机拍照；每张需只有本人。声纹可选 WAV，也可以逐段录音，
每段至少三秒。采集只是准备样本；勾选本次明确同意并点击 **登记样本** 后，才
开始本地特征提取和登记。

已有登记需要额外勾选 **替换该成员原来的同类登记**。临时样本只在窗口内存中保存，
不进浏览器存储；登记完成、换人、离开页面或手动清除时释放。
人脸和声纹分别显示登记状态并可撤销。

### 识别一次

可以单独选择照片 / 录音，或点击 **拍照识别** / **录音识别**。相机弹窗只提供一次
明确的预览和快照，拍摄后、按 Escape、关闭弹窗或离开页面都关闭摄像头轨道。

界面分别显示候选、未知、歧义、质量不足和未登记，并把相似度标为余弦得分。
它不会把数值显示为“识别正确率”，也不会因为一个候选就开放家长权限。
未通过人脸检测质量检查、多人照片或模型缺失会显示实际错误。

## 6. 工具权限和安全连接

OpenCode 的 `browser` / `deepseek-search` 由已有配置继承。**服务与设置** 显示实际
继承状态；没有配置时明确显示缺失，不安装另一个未知搜索实现。

工具需要额外确认时，**对话** 底部显示具体操作、目标、说明与输入参数。家长可
**仅允许这一次** 或 **拒绝**；没有“一直允许”按钮。请求超时、取消或所属轮次变更，
由后端拒绝过期的确认。内容过长不能完整呈现时，批准按钮停用。

设备凭据位于折叠区域。新 token 只在签发响应中展示一次，支持隐藏清除与撤销，
不保存到 `localStorage` 或事件日志。它面向支持 v3、已经信任 WSS 证书的设备。
旧版 LAN 软配对和 mDNS 发现继续只是诊断入口，不能因此上传私密音频。

## 7. 当前限制

- 没有在本轮运行 UI，也未执行 TypeScript 编译、打包或硬件联调；源码接线不等于已验证可运行。
- 麦克风 / 摄像头仍受 macOS、WebKit、设备权限和硬件可用性影响；权限失败时有文件输入入口。
- 没有自动常驻监听、自动人脸采集、ASR 前环境录音上传或识别后自动叫出姓名。
- 当前网页是 Mac iframe 呈现；ESP 的正式媒体播放器和设备端安全 v3 接线是独立工作。
- 记忆与识别阈值没有做家庭样本校准；没有人脸 / 录音防重放能力。

状态每 15 秒读取一次元数据，活动轮次的工具权限每 3 秒查看一次并接受实时事件。
不会通过定时任务调用模型推理或启动摄像头 / 麦克风。旧 `?mock=1` 仅保留旧界面的
预览用途；新的“小呆”页明确标为未连接服务，不假造实际语音或识别结果。
