## 实际故障与修复

1. **Mac 最初不能编译**：家庭时间、修订和序号使用 `u64`，锁定版本的 rusqlite 默认不提供对应的 SQLite 转换。启用上游 `fallible_uint`，沿用 SQLite 有符号整数的可表示范围，没有改表或提升依赖版本。
2. **固件最初不能编译**：USB 事件名称表缺少新加入的 `barge.in`，与事件总数的编译期检查不符。补齐名称并保留检查。
3. **唤醒后重启**：实板检测到完整唤醒词（0.993），本地应答末尾触发 `bot_audio_out` 栈溢出。静音排空原先在任务栈分配 2,560 字节；改用唯一音频 owner 已分配的输出缓冲，保留 codec 写入和尾音排空之后才发 DONE 的顺序。
4. **连续图片与摄像头重开争用 PSRAM**：旧工作区第二张拼写图片报告 `image_no_memory`，配套语音因此未播；退出设置还出现 DVP 备用帧分配失败。USB 预览的单一编码任务现在复用同一块 RGB565 工作区，释放 192,000 字节，摄像头生产者仍有独立帧槽。相机开启时可用 PSRAM 由约 0.32 MB 升至 0.50 MB。单独复用工作区后，空闲时两次退出设置均恢复，但播过两张图后再次退出设置仍出现连续内存不足。调整分配顺序也未解决，已撤回。核对固定版本乐鑫 DVP 实现：在应用未排入帧槽时，IDF 使用自己的备用 DMA 帧。最终配置只保留一个 V4L2 采集槽、DVP 备用帧和一个推理副本，比之前少占 614,400 字节；仍在推理前归还 DMA 帧。
5. **回执混入了计划值**：修复前第二段硬件报告 0 帧 / 0 字节，SQLite 却记录整段预备的 186,626 字节。现在区分发送端计数与设备计数；未上报的值保留为空，图片不可用及其原始错误也进入该段记录。

## 本机语音与实板

- 正式 Mac 控制台导入 3.2 秒合成中文 WAV。真实本地 RMA Qwen3-ASR 转写“三加四等于几”，OpenCode 2.2.5 经 GLM Coding Plan（`glm-5.3`）回答“三加四等于七。”并生成语音。单次总耗时 18.393 秒，其中 ASR 1.564 秒、OpenCode 调用 15.413 秒，不是性能基准。
- 核对片上分区表与构建分区表一致后，只写 factory 应用（`0x10000`），esptool 写后哈希校验通过；未写 bootloader、分区表、NVS、模型或 storage 分区。最终镜像 **8,336,096 字节**，SHA-256 `5df57907e4ddb5be9b254c89e061fd4f0140e33761976265ac55924811d0dc58`；8 MiB 应用分区只剩 **52,512 字节**。
- 设备使用已有配对和 Bonjour 重新连接；控制通道为认证 WSS，音频沿该配对配置所选的带认证局域网 TCP 通道传输。没有改变网络安全模式。Mac 扬声器向设备麦克风播放合成语音；未向识别器直接注入 PCM。普通语句和单叫“小呆”未触发；完整词有命中也有漏识，较低播放音量下出现真实 `audio_too_quiet`。不以这些样本估算准确率。
- **最终镜像端到端**：普通语句和单叫“小呆”未触发；完整“小呆小呆”命中 0.992。设备播完本地应答后从麦克风提交 **1,056 帧**。真实 ASR → GLM → Mac TTS 返回两段：“苹果的英语单词是 apple”“按顺序拼是：a、p、p、l、e，五个字母”。每段均在 SQLite 查到独立的文字绘制、图片绘制、音频开始、硬件音频完成、整段完成回执。第一段 **109 帧 / 69,584 字节**，第二段 **266 帧 / 169,668 字节**；末段播完后才进入追问等待。
- **播图后再进出设置**：最终镜像在对话前、两张图及语音播完后退出设置，均得到新的相机帧和有效推理。按主机观测，从关闭设置的触摸命令到确认新相机帧约 **1.9 秒 / 1.7 秒**；播图后恢复时已发布 426 次视觉结果，当次推理 37 ms。空闲 14 秒样本新增 65 次视觉发布（约 4.6 次/秒），没有宣称应用取得传感器全部 15 fps。恢复后可用 PSRAM 为 1,123,716 字节。
- **USB 预览与收尾**：正式 Mac 应用的“设备连接”页同时显示 400×240 的屏幕和相机图像；抽查 19 帧时校验/同步异常为 0，驱动欠载日志为 0。较长的独立串口采集器丢弃过 4 个无效数据包，因此不声明长时间零丢包。已断开测试预览。设备回到空闲，保留已配对连接；临时启用的语音回复已关闭，音量 30、未静音、唤醒阈值 80，Mac 输出音量恢复至 12.5%。
- 在中间版本上也完成过一次双图双语音（69,584 / 189,970 字节）。另有一次设备在测试语音送入前就提交了安静片段，ASR 拒绝；该次不计通过。
