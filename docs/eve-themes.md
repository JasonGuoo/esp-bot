# EVE 表情主题（2026-11-07）

以用户提供的 [eveface_design.png](eveface_design.png) 为视觉参考，新增 **EVE**：
黑色背景、青蓝实心眼睛、横向扫描线与轻量光晕，无瞳孔、无嘴。
两只完整眼睛使用 attention 提供的同一个视线向量平移；左右张望不改变眼睛比例，
避免产生转头或两只眼睛大小不一的效果。表情不重新选择目标或覆盖注视方向。
唤醒、被动生命周期、摄像头和运动控制的职责不变。

## 默认与兼容

- 默认主题为 `eve`，由 `shared/themes.json.default_theme` 指定；固件通过生成的
  `FACE_DEFAULT_THEME_INDEX` 选择，不依赖列表顺序。
- 原风格命名为 **经典线条**，保留薄荷绿、樱花粉、香芋紫、奶油黄、天空蓝五种配色。
  原 ID `mint` / `sakura` / `lavender` / `butter` / `sky` 不变。
- 已保存的有效主题选择继续优先，不强制覆盖 NVS / localStorage。无选择或保存 ID
  已失效时使用 EVE。已有设备若保存了经典主题，可在外观页选择 EVE 并应用。
- 经典线条原有表情保留；新增语义使用最接近的原有表情。EVE 的细分眼形为独立驱动。

## 在 Bot 上使用

轻点屏幕 → 右上角齿轮 → **外观**。右侧选择主题，左侧显示候选主题的大预览。
用 `<` / `>` 翻看 24 种表情；翻到末尾后循环。
点 **应用** 后返回正常表情，并沿用应用层现有的 NVS 保存流程。
点 **返回** 放弃候选，不保存。预览不向 runtime 发出表情、唤醒或追踪命令。
切换驱动若分配失败，保留现有外观并显示失败，不提交保存。

外观页采用三列、两行主题卡片；未来更多主题可在右侧区域纵向滚动。
浏览器 `/preview/` 提供同一组主题、表情与设置操作，选择仅保存到浏览器。

在参考图 20 种基础上另有 `sad`（难过）、`affection`（喜欢）、`relieved`（放心）
和 `overjoyed`（特别开心·水汪汪），共 24 种可选预览；另兼容 `blink` / `bored` /
`drowsy` / `speaking`，共 28 个合法表情 ID。仅 `overjoyed` 有眼内反光，不参与普通
待机或近脸微笑；当前可通过 USB 显式预览，自动语义触发需未来对话链路提供。
runtime、Mac 语义场景与 LAN 验证、旧 Python 服务均接受这些 ID；设备是否采用
远程表情仍受原权限约束；新增的预览是有线 USB 调试入口，8 秒后恢复自动行为。

`shared/eve-expressions.json` 保存闭合三次贝塞尔轮廓、表情语义与预览顺序。
`python3 tools/generate_face_themes.py` 同时生成固件主题/表情表、浏览器表情数据、
Mac Rust 白名单；`--check` 检查产物是否同步。
固件 `renderer_eve.c` 用现有 LVGL 软件线段绘制轮廓、扫描线与有限光晕，不增加
矢量后端或大位图缓冲。浏览器使用相同轮廓的 SVG；光晕合成和抗锯齿不保证逐像素一致。
新主题通过 `face_renderer_driver_t` 注册，颜色和眨眼/注视缓动参数放在主题清单中。

## 最初 EVE 主题的验证记录

使用现有本机 ESP-IDF v6.1 / S31 工具链完成完整固件构建。
最终应用 7,361,488 字节，8 MiB 应用分区剩余约 12%。
本机自动检查覆盖默认主题、旧 ID 兼容、取消/应用语义、20 种不同眼形、两眼共同
注视位移，以及生成产物同步。浏览器实际检查设置页、20 项预览循环、候选不写入、
取消恢复、应用保存、刷新恢复与 390 px 窗口布局（操作按钮无重叠或越界）。
Mac 本地场景规范化和 LAN 消息校验共 8 项通过；旧 Python 服务的主题与 24 个表情
入队/出队检查通过，均未调用模型或启动媒体采集。
